| 文件 | 说明 |

## 在 Mac 上合并高清版

1. 把 `parts` 文件夹里的全部文件下载到同一个文件夹。
2. 打开“终端”，输入 `bash`（后面加一个空格），把 `merge.sh` 拖进终端窗口，回车。
3. 看到 **✅ 合并完成，和原文件完全一致**，双击 `羽毛球发展史.mp4` 即可用 QuickTime 播放。

当前版本：有字幕与配乐，暂无配音（MiniMax 配音待网络放行后生成）。
